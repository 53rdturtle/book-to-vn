You are staging characters for one chapter of prose in a visual novel. Your
ONLY job in this pass is to decide when each speaking character enters the
stage (which slot, which expression), when their expression should change,
and when they leave. Output MUST be a single JSON object that validates
against the schema below. Return JSON only — no prose, no code fences.

SCHEMA:
{SCHEMA}

KNOWN CAST for this chapter (you MAY ONLY reference these ids as `id`; do not
invent new ones — a prior pass already decided who speaks):
{CHAPTER_CAST}

PER-SEGMENT SPEAKERS (decided by the prior pass — use this to time entries/
exits and pick expressions that fit the tone of the line being spoken):
{SPEAKER_LINES}

RULES:
- chapter_id MUST equal "{CHAPTER_ID}".
- `stage` is an ordered list of entries, each anchored to a `before_seg_id`.
  An entry applies JUST BEFORE that segment is spoken.
- `before_seg_id` values MUST be in strictly non-decreasing order and MUST
  appear in the PER-SEGMENT SPEAKERS list above.
- Emit a `show` entry the FIRST time a character speaks, anchored to (or
  before) their first `say` segment. Pick `slot` from {left, middle, right}:
    - If only one character is on stage, prefer "middle".
    - If two characters are on stage together, use "left" and "right".
    - If a third enters, use the remaining slot.
- Once you assign a character to a slot, keep them in that slot for the rest
  of the chapter. Do not re-slot someone who is still on stage.
- Emit a new `show` entry (same id, same slot, new `expr`) when the emotional
  tone of their line clearly changes. Be judicious — do not change expression
  every line. A single expression can cover a run of neutral lines.
- `expr` MUST be one of: neutral, smile, sad, angry, surprised, worried,
  thinking. No other values are accepted. Pick the one that best matches the
  tone of the line they are about to speak.
- Emit a `hide` entry when the prose says a character leaves, or when they
  will not speak again for a long run of segments and the scene has moved on.
  Do not hide and immediately re-show the same character.
- Narrator segments do NOT need any stage entry on their own. Stage state
  carries over across narrator lines.
- It is fine for `stage` to be empty if this chapter has no character dialogue
  (pure narration), but that is rare.
